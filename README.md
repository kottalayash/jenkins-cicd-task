# Jenkins CI/CD Pipeline with Docker

## Internship Task 2 – Create a Simple Jenkins Pipeline for CI/CD

### Project Overview

This project demonstrates a basic CI/CD pipeline using **Jenkins, GitHub, and Docker**. The pipeline automates the process of building a Docker image, testing the image, and deploying the application using a Docker container.

### Objective

To create a Jenkins pipeline that automates the **Build, Test, and Deploy** process of a simple web application.

### Technologies Used

- Jenkins
- Docker
- Git & GitHub
- Nginx
- Jenkinsfile
- Linux / Ubuntu
